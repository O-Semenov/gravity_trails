# Ресурсы для Gravity Trails

В эту директорию помещаются изображения кузовов автомобилей. При компиляции игры с помощью `go:embed` они вшиваются в исполняемый бинарный файл.

Имена файлов должны соответствовать `ID` пресетов:
- `buggy.png` (или `.jpg` / `.jpeg`) — Багги
- `sport.png` — Спорткар
- `truck.png` — Грузовик
- `bike.png` — Мотоцикл

---

## Требования к изображению

1. **Формат:** Рекомендуется **PNG с прозрачным фоном** (Alpha-каналом). Если использовать JPG, вокруг кузова будет виден белый или черный прямоугольный фон.
2. **Проекция:** Вид строго сбоку (Side View/Profile), направленный вправо (по ходу движения машины).
3. **Колеса:** 
   - Настоятельно рекомендуется использовать изображения **без колес** (с прозрачными вырезами/арками под колеса).
   - Физические колеса игры (шины и крутящиеся диски) рисуются поверх изображения кузова. Если на картинке будут свои колеса, они наложатся на игровые и будут выглядеть странно.

---

## Схема привязки точек (UV-координаты)

Для того чтобы картинка деформировалась и растягивалась вместе с физической рамой, но при этом ее внешние края (бамперы, крылья, спойлеры) не обрезались, используется **5-точечная схема экстраполяции**.

Мы задаем в файле `vehicle_presets.go` относительные координаты пяти ключевых точек на вашей картинке (в диапазоне от `0.0` до `1.0` от краев картинки):

```
(0, 0) Верхний левый угол картинки                                      (1, 0) Верхний правый угол картинки
+---------------------------------------------------------------------------------------------------------+
|                                                                                                         |
|                     Левая точка крыши                        Правая точка крыши                         |
|                     (UvTopLeftX, UvTopLeftY)                 (UvTopRightX, UvTopRightY)                 |
|                               *──────────────────────────────────────*                                  |
|                              / \                                    / \                                 |
|                             /   \             Рама кабины          /   \                                |
|                            /     \                                /     \                               |
|                           /       \            Центр             /       \                              |
|                          /         \       * (0.5, 0.5)         /         \                             |
|                         /           \                          /           \                            |
|                        /             \                        /             \                           |
|                       /               \                      /               \                          |
|                      /                 \                    /                 \                         |
|                     /                   \                  /                   \                        |
|                    /                     \                /                     \                       |
|                   /                       \              /                       \                      |
|                  *                         \            /                         *                     |
|           Левое колесо                      \          /                   Правое колесо                |
|       (UvLeftWheelX, UvLeftWheelY)           \        /               (UvRightWheelX, UvRightWheelY)    |
|                                               \      /                                                  |
|                                                \    /                                                   |
+─────────────────────────────────────────────────*──*────────────────────────────────────────────────────+
(0, 1) Нижний левый угол картинки               ( колеса )                                (1, 1) Нижний правый
```

### Как это работает:
1. Игра определяет направление и базу между колесами, а также высоту от колес до крыши.
2. Игра автоматически вычисляет, где на экране должны оказаться **4 внешних угла картинки** (`U=0, V=0`, `U=1, V=0` и т.д.), чтобы колеса и крыша на вашей картинке совпали с физическими колесами и рамой игры.
3. Происходит рендеринг всей картинки, растянутой по этим углам. Бамперы и спойлеры выходят наружу ровно настолько, насколько они выступают на исходной картинке!

## Как подогнать свою картинку и точки?

Если колеса игры не попадают в арки вашей картинки, выполните следующие шаги:

1. Откройте картинку в любом графическом редакторе (Figma, Photoshop, Paint.NET и др.).
2. Узнайте полный размер картинки в пикселях (например, ширина `W = 800`, высота `H = 400`).
3. Найдите пиксельные координаты четырех ключевых точек на картинке:
   - **Центр заднего (левого) колеса:** например, `X = 144`, `Y = 288`
   - **Центр переднего (правого) колеса:** например, `X = 656`, `Y = 288`
   - **Задний верхний угол кабины (крыша):** например, `X = 224`, `Y = 80`
   - **Передний верхний угол кабины (крыша):** например, `X = 576`, `Y = 80`
4. Переведите эти значения в относительные координаты (поделите X на ширину `W`, а Y на высоту `H`):
   - `UvLeftWheelX` = `144 / 800 = 0.18`
   - `UvLeftWheelY` = `288 / 400 = 0.72`
   - `UvRightWheelX` = `656 / 800 = 0.82`
   - `UvRightWheelY` = `288 / 400 = 0.72`
   - `UvTopLeftX` = `224 / 800 = 0.28`
   - `UvTopLeftY` = `80 / 400 = 0.20`
   - `UvTopRightX` = `576 / 800 = 0.72`
   - `UvTopRightY` = `80 / 400 = 0.20`
5. Впишите эти значения в `VehiclePresets` в файле `vehicle_presets.go` для вашей машины.
